# Open-house flyer

Make a local flyer for one property and a realtor's approved public business identity. Do not assume access to a private template catalog or MLS account.

## Collect the essentials

Get the listing address or authorized listing link/export, open-house date, local time zone and hours, chosen style, realtor's public business details, brokerage requirements and destination for a QR. Ask for an approved portrait and permission to use listing photos. Offer three descriptive style choices if no catalog is supplied: photo-led editorial, clean minimal, or warm neighborhood. Let the realtor pick before designing. A supplied reference controls hierarchy, spacing and image treatment; use only cleared fonts and artwork.

Use a company-approved connector or browser for authorized listing access. The user signs in personally. If access is unavailable, ask for a permitted listing export and photos. Do not bypass a login, scrape restricted MLS data, or use private agent remarks in public copy.

## Source before design

Open the current source and record its as-of date in `SOURCES.md`. Create a small fact table for address, listing status, description, beds, baths, area, open-house schedule and public contact details. Distinguish the user's event instructions from listing facts. Flag conflicts for the user to resolve; do not silently remove a field they asked to include. Keep a working draft with unresolved fields clearly identified in the review note, never as invented facts in a final export.

Download authorized full-resolution listing photos and record their origin. Use real photos of this property. Crop and correct exposure carefully, without changing fixtures, views, room size or condition. Never substitute a generated room or a neighboring home's photo. Avoid mortgage pricing, payment examples, lending program claims and unsourced neighborhood claims. Include required brokerage and professional disclosures only from verified user-supplied details and company instructions.

## Build and inspect

Use whatever local design capability is available, such as HTML/CSS printed to PDF or a document/image library. If only chat is available, return copy and a layout plan and state that exports have not been created. Do not refer to unbundled private scripts.

Create an editable source, US Letter PDF, 2550x3300 print PNG, a phone preview and a plain-text copy file. If the user needs a social crop, also compose a 1080x1350 version rather than stretching the print artwork. Put the headline, property image and event time ahead of secondary details. Preserve legible type and clean margins. Ask the printer for bleed requirements when a full-bleed job is requested.

Use a verified public HTTPS destination for the QR. If no live agent page exists, leave the QR out of the final flyer and explain the missing destination. A local preview is not a usable printed QR destination. Decode a rendered QR and require an exact URL match; test the live page on mobile when authorized.

Inspect the actual PDF and PNG at print size and around 375 px wide. Check facts, image quality, crop, date/time, contact spelling, brokerage details, QR and overflow. Compare the final render side by side with the chosen style. Fix defects before delivering; arrange an independent review if one is available.

## Offer the next step

Deliver files and a short source/QA note. Offer to prepare a caption and collaboration invitation using explicitly supplied handles. Keep those as drafts. Posting, inviting a collaborator or messaging a realtor requires the user's approval of the exact asset, copy, account and handles, plus a supported platform workflow. Do not claim an invitation was accepted without live evidence.

## Try it

"Use open-house-flyer. Here are my permitted listing export, photos, business details and an editorial style reference. Build print and phone versions, then draft a caption with an optional collab invitation. Publish nothing."
