# Open-house flyer

`open-house-flyer` | Realtor and loan officer kit

Builds a sourced open-house flyer in the realtor's chosen style from permitted listing photos and facts, with print and phone exports.

| | |
|---|---|
| **What** | Builds a sourced open-house flyer in the realtor's chosen style from permitted listing photos and facts, with print and phone exports. |
| **When** | A listing is going to open house. |
| **Who it is for** | Realtors and the loan officers who support them |
| **Needs** | Claude Code or Claude app with file creation |
| **Customize** | Point it at your own style samples. |

## Install

Mac or Linux:
```bash
curl -fsSL https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.sh | bash -s -- open-house-flyer
```

Windows PowerShell:
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.ps1))) open-house-flyer
```

Or by hand: copy this `open-house-flyer` folder into `~/.claude/skills/` so you have `~/.claude/skills/open-house-flyer/SKILL.md`. On Windows `~` is your user folder (`%USERPROFILE%`). Then start a new Claude Code session.

## Try it

> Use open-house-flyer with this listing export and photos. Build print and phone drafts. Publish nothing.
