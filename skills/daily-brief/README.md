# Daily brief

`daily-brief` | Inbox and daily rhythm

A morning brief from your calendar, recent email and dated industry news, with a week-ahead on Monday and a next-week plan on Friday. Read and draft only.

| | |
|---|---|
| **What** | A morning brief from your calendar, recent email and dated industry news, with a week-ahead on Monday and a next-week plan on Friday. Read and draft only. |
| **When** | Every morning before the first meeting. |
| **Who it is for** | Loan officers and realtors, easy to adapt to any field |
| **Needs** | Claude with Calendar and Gmail connectors, or pasted agenda |
| **Customize** | Swap the news topics for your industry. |

## Install

Mac or Linux:
```bash
curl -fsSL https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.sh | bash -s -- daily-brief
```

Windows PowerShell:
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.ps1))) daily-brief
```

Or by hand: copy this `daily-brief` folder into `~/.claude/skills/` so you have `~/.claude/skills/daily-brief/SKILL.md`. On Windows `~` is your user folder (`%USERPROFILE%`). Then start a new Claude Code session.
