# Realtor showcase page

`realtor-showcase-page` | Realtor and loan officer kit

A mobile one-page get-to-know-your-agent site plus a QR for the flyer, from approved realtor facts, photos and public contact details.

| | |
|---|---|
| **What** | A mobile one-page get-to-know-your-agent site plus a QR for the flyer, from approved realtor facts, photos and public contact details. |
| **When** | You want a flyer QR that goes somewhere better than a listing page. |
| **Who it is for** | Realtors and the loan officers who support them |
| **Needs** | Claude Code or Claude app with file creation |
| **Customize** | Swap the sections for what the agent wants to show. |

## Install

Mac or Linux:
```bash
curl -fsSL https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.sh | bash -s -- realtor-showcase-page
```

Windows PowerShell:
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.ps1))) realtor-showcase-page
```

Or by hand: copy this `realtor-showcase-page` folder into `~/.claude/skills/` so you have `~/.claude/skills/realtor-showcase-page/SKILL.md`. On Windows `~` is your user folder (`%USERPROFILE%`). Then start a new Claude Code session.
