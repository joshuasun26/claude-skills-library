# Comment-to-DM funnel

`comment-to-dm-funnel` | Realtor and loan officer kit

Stages an Instagram comment keyword to DM link to landing-page capture flow for a CRM that supports it, with consent and duplicate-send checks.

| | |
|---|---|
| **What** | Stages an Instagram comment keyword to DM link to landing-page capture flow for a CRM that supports it, with consent and duplicate-send checks. |
| **When** | A post is about to go out with a comment-to-get-it CTA. |
| **Who it is for** | Anyone running comment-a-keyword calls to action |
| **Needs** | A CRM with Instagram DM automation |
| **Customize** | Keyword, DM copy and landing page per post. |

## Install

Mac or Linux:
```bash
curl -fsSL https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.sh | bash -s -- comment-to-dm-funnel
```

Windows PowerShell:
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.ps1))) comment-to-dm-funnel
```

Or by hand: copy this `comment-to-dm-funnel` folder into `~/.claude/skills/` so you have `~/.claude/skills/comment-to-dm-funnel/SKILL.md`. On Windows `~` is your user folder (`%USERPROFILE%`). Then start a new Claude Code session.
