# Voice profile

Use this for a person's own writing, with their permission. Learn how they write without copying private facts, other people's language, or another person's identity.

## Gather a useful sample

Ask whether the user wants a profile, a draft using an existing profile, or both. For a new profile, ask for an authorized sent-mail connection or a redacted export. Never request a password. Use only a company-approved environment. If email access is unavailable, work from pasted redacted samples and state the smaller sample size.

Read the most recent 100-200 substantive messages actually authored by the user. A useful message contains original explanation, a request, an opinion, or relationship context. Exclude automated mail, newsletters, bulk templates, signatures, disclaimers, one-line acknowledgments, and quoted thread history. Deduplicate repeated sends. Separate dictated drafts from polished emails when the distinction is known. Do not open attachments unless needed and authorized.

Keep the search date range and counts: inspected, excluded, deduplicated, and retained. If fewer than 100 qualify, report the shortfall and produce a provisional profile rather than inventing evidence. Do not save a raw inbox export. Remove recipients, addresses, transaction details and borrower information before any persistent note. Use anonymous sample labels for evidence; paraphrase examples so the profile can be shared safely.

## Build the profile

Describe observed patterns, with confidence and anonymous evidence labels:

- Typical opening and closing, sentence and paragraph length, contractions, punctuation and vocabulary.
- How the writer asks for action, follows up, explains complexity, disagrees and expresses warmth.
- Differences between a familiar colleague, a new business contact and a client. Do not flatten these into one tone.
- Repeated expressions that belong to the writer, plus language they avoid when supported by samples or explicit preferences.
- A few short fictional before/after examples that demonstrate the style without retaining personal facts.

Separate observations from preferences the user explicitly states. Do not infer biography, beliefs, promises, professional qualifications or legal positions from a style pattern. Ask the user to correct the profile and approve it before treating it as a standing preference. Save `VOICE-PROFILE.md` only when local file creation is available and the user requests persistence; otherwise return it in chat. Explain that a chat or skill upload alone does not guarantee future memory.

## Draft with the profile

Get the recipient relationship, purpose, facts to include and desired next action. Use the approved profile and the current thread. Preserve every requested fact; flag a missing fact instead of supplying one. Never invent an attachment, availability, offer, promise or willingness to call. A familiar writing style does not authorize a new commitment. For a loan officer's lending or legal message, keep approved facts intact and flag substantive review separately from style.

Return the draft and a brief note on any unresolved factual issue. Use plain language, no emojis or em-dashes. Keep it as a draft; no sending, mailbox changes or automatic follow-up scheduling.

## Try it

"Use voice-profile. Review my last 150 substantive sent emails in this approved environment. Build a redacted profile, show your coverage, and give me two fictional examples. Send nothing."
