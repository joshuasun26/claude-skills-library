# Research gauntlet

`research-gauntlet` | Quality gates

Two or three models research the same question independently, then a skeptical critic attacks the merged answer before you act on it.

| | |
|---|---|
| **What** | Two or three models research the same question independently, then a skeptical critic attacks the merged answer before you act on it. |
| **When** | Comparing tools, vendors, strategies, or checking a claim from a video. |
| **Who it is for** | Anyone making a costly decision from research |
| **Needs** | Two models if you have them; one works with weaker independence |
| **Customize** | The brief template in step 1 is the part to tailor. |

## Install

Mac or Linux:
```bash
curl -fsSL https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.sh | bash -s -- research-gauntlet
```

Windows PowerShell:
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.ps1))) research-gauntlet
```

Or by hand: copy this `research-gauntlet` folder into `~/.claude/skills/` so you have `~/.claude/skills/research-gauntlet/SKILL.md`. On Windows `~` is your user folder (`%USERPROFILE%`). Then start a new Claude Code session.
