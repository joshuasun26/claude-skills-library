`browser-agent-tasks` | Realtor and loan officer kit

Prepares supervised browser workflows in Claude in Chrome for comps, CRM changes, pricing, letter drafts and reconciliation, with you approving each step.

## Install

Mac or Linux:
```bash
curl -fsSL https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.sh | bash -s -- browser-agent-tasks
```

Windows PowerShell:
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.ps1))) browser-agent-tasks
```

Or by hand: copy this `browser-agent-tasks` folder into `~/.claude/skills/` so you have `~/.claude/skills/browser-agent-tasks/SKILL.md`. On Windows `~` is your user folder (`%USERPROFILE%`). Then start a new Claude Code session.
