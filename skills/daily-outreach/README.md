# Daily outreach

`daily-outreach` | Realtor and loan officer kit

A four-a-day relationship habit: two sphere contacts and two realtors, with call templates and one-minute after-call notes. Draft only.

| | |
|---|---|
| **What** | A four-a-day relationship habit: two sphere contacts and two realtors, with call templates and one-minute after-call notes. Draft only. |
| **When** | Every workday, ideally before noon. |
| **Who it is for** | Loan officers and realtors building referral relationships |
| **Needs** | Claude app or Claude Code, Your contact list |
| **Customize** | Change the daily mix and templates to fit your business. |

## Install

Mac or Linux:
```bash
curl -fsSL https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.sh | bash -s -- daily-outreach
```

Windows PowerShell:
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/joshuasun26/claude-skills-library/main/install.ps1))) daily-outreach
```

Or by hand: copy this `daily-outreach` folder into `~/.claude/skills/` so you have `~/.claude/skills/daily-outreach/SKILL.md`. On Windows `~` is your user folder (`%USERPROFILE%`). Then start a new Claude Code session.
